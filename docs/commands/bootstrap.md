# bootstrap

Create `.hookset.toml` and install hooks in one step.

## Synopsis

```
hookset bootstrap [--template <name>] [--yes]
```

## Description

`hookset bootstrap` is the fastest way to get started. It:

1. Auto-detects your project language from `go.mod`, `pyproject.toml`, `package.json`, or `Cargo.toml`
2. Writes a sensible `.hookset.toml` template for that language
3. Runs `hookset init` to install the hooks

If language detection finds no match, it falls back to a minimal template with a `pre-commit` placeholder.

## Flags

| Flag | Description |
|------|-------------|
| `--template <name>` | Force a specific template (`go`, `typescript`, `python`, `rust`) |
| `--yes` | Skip the confirmation prompt |

## Available templates

| Template | Detected from | Includes |
|----------|--------------|---------|
| `go` | `go.mod` | `go vet`, `go test ./...` on `pre-push` |
| `typescript` | `package.json` | `eslint --cache`, `tsc --noEmit`, `prettier --check` |
| `python` | `pyproject.toml` | `ruff check`, `mypy`, `pytest` |
| `rust` | `Cargo.toml` | `cargo clippy`, `cargo test` |
| `minimal` | fallback | empty `pre-commit` placeholder |

## Examples

```bash
# Auto-detect language and create .hookset.toml
hookset bootstrap

# Force TypeScript template (e.g. in a monorepo with go.mod at root)
hookset bootstrap --template typescript

# Non-interactive (CI scaffolding, dotfiles setup)
hookset bootstrap --yes
```

## What gets created

```toml
# .hookset.toml — generated by hookset bootstrap

[[hooks]]
name    = "go-vet"
event   = "pre-commit"
command = "go vet ./..."

[[hooks]]
name    = "go-test"
event   = "pre-push"
command = "go test ./..."
```

After bootstrap, edit `.hookset.toml` to add or remove hooks. Re-run
`hookset init` (or `hookset bootstrap --yes`) to apply changes.
